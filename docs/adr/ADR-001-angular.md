# ADR-001: Use Angular as the Frontend Framework

## Status

Accepted

## Context

PersonalWorkspace requires a structured, maintainable, and responsive frontend application.

The project should also align with the selected professional stack, where Java and Spring Boot will be the main backend technologies and Angular will be used for frontend development.

## Alternatives Considered

- Angular
- React
- Vanilla JavaScript

## Decision

Use Angular as the frontend framework.

## Rationale

Angular provides:

- A structured application architecture.
- Built-in routing.
- Dependency injection.
- Component-based development.
- TypeScript integration.
- Tooling through Angular CLI.

It also aligns with the professional stack selected for this portfolio.

## Consequences

Positive:

- Consistent project structure.
- Good maintainability.
- Clear separation of responsibilities.
- Strong TypeScript integration.

Trade-offs:

- Higher initial complexity than vanilla JavaScript.
- More framework conventions to learn.
